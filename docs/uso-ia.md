# Declaración de uso de IA

Se utilizó un asistente de IA como apoyo para corregir el HTML, mejorar los estilos, implementar el carrito básico y redactar documentación. Las comprobaciones descritas en la bitácora se ejecutaron con Node.js; la prueba funcional del carrito usó un DOM simulado. Las imágenes del proyecto no se generaron ni modificaron con IA.
