# Uso de herramientas de IA

Para preparar este primer avance se utilizó un asistente de IA como apoyo de implementación y revisión. La ayuda se aplicó a las tareas que aparecen en los commits locales de `feat/avance-luis`:

- corregir el HTML y los nombres mostrados para las cuatro cartas;
- reorganizar el CSS para pantallas de escritorio y móviles;
- implementar el carrito básico en JavaScript;
- redactar esta nota y la bitácora a partir de los cambios y comprobaciones realizados.

También se usó Node.js para comprobar partes del HTML y CSS y para ejecutar una prueba del carrito con elementos DOM simulados. Esa prueba no representa una revisión visual en navegador. Las imágenes del proyecto se conservaron. No se generaron ni modificaron imágenes con IA.

El resultado de este avance no incluye pagos, bases de datos ni servicios externos. Los cambios y commits registrados corresponden al trabajo efectuado en este repositorio; esta nota no atribuye contribuciones a otras personas.
