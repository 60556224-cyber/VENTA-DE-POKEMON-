# Venta de Cartas Pokémon


## Descripción


**Venta de Cartas Pokémon** es una tienda virtual desarrollada como proyecto grupal para el curso de Diseño Web de la Universidad Continental.


El sitio permite visualizar un catálogo de cartas Pokémon, agregar productos a un carrito de compras, modificar cantidades, eliminar productos y consultar el total de la compra.


El proyecto fue desarrollado utilizando únicamente:


HTML5
CSS3
JavaScript puro
No se utilizaron frameworks, bibliotecas externas ni plantillas prediseñadas.


## Objetivo


El objetivo del proyecto es crear una tienda en línea funcional y responsive para la venta de cartas Pokémon, aplicando los conocimientos aprendidos sobre:


Estructura semántica con HTML.
Diseño responsive con CSS.
Manipulación del DOM.
Manejo de eventos.
Programación orientada a objetos.
Uso de localStorage.
Validación de formularios.
Creación de un carrito de compras.
## Público objetivo


El sitio está dirigido a:


Coleccionistas de cartas Pokémon.
Jugadores del juego de cartas Pokémon.
Personas interesadas en comprar cartas individuales.
Aficionados y seguidores de Pokémon.
## Funcionalidades


El proyecto incluye las siguientes funcionalidades:


-Visualización del catálogo de cartas Pokémon.

-Productos organizados por categorías.
-Búsqueda de productos por nombre.
-Filtro por categoría.
-Visualización del detalle de cada producto.
-Agregar productos al carrito.
-Aumentar o disminuir la cantidad de productos.
-Eliminar productos del carrito.
-Vaciar el carrito completo.
-Control de stock disponible.
-Cálculo del subtotal.
-Cálculo del IGV.
-Cálculo del costo de envío.
-Aplicación de cupones de descuento.
-Persistencia del carrito mediante localStorage.
-Formulario de contacto o compra.
-Validación de los datos del formulario.
-Diseño adaptable para computadora, tablet y celular.
